# Japanese Web Copy

## 基本姿勢

サイトの発信者が訪問者に伝える文章を書く。第三者が経歴を調査・評価したような語りや、企業広告のような文句を持ち込まない。文の長さやカード間の均一さより、事実と自然な日本語を優先する。

## 作業手順

1. **事実を抽出する。** 表示文、データ、リンク先、本人の執筆例を確認し、名称、年次、本人の担当、チームの成果、技術、資料を分けて記録する。既存文にあるだけの情報と外部資料で確認できた情報を区別する。評価・推測・意図は事実と混ぜない。本人の文章だと識別できない既存文を文体の証拠にしない。
2. **各文章の必要性を判定する。** 見出し・写真・前後の文だけで伝わる説明は削除する。役割のないキャッチコピー、見出しを言い直す導入、同じ実績を繰り返すカードも削除を先に検討する。削除する場合は、固有の事実とリンクが他の場所で残るか確認する。
3. **必要な情報だけで書く。** 元の文型は引き継がなくてよい。作品なら「何を作ったか」、必要なら「どう動くか」「本人は何を担当したか」「何が起きたか」を、確認できる範囲で書く。本人の担当が不明なチーム作品は担当を創作せず、共同開発・参加など確認できる範囲にとどめる。受賞・順位は個人かチームかを明示する。年月は確認できる期間に限る。
4. **編集者として読み直す。** 抽象的な総括、宣伝文句、調査者の視点、不自然な体言止め、意味のない形容詞、他サイトにも置ける汎用文、担当範囲を曖昧にする文、見出しや周囲との重複を探す。まず削除を検討し、残す場合は具体的な情報が増えるか確認する。無理な短文化や文章量の統一もしない。
5. **表示と出典を照合する。** 共通データを使う全ページを見直し、事実・年次・リンクの欠落がないか確認する。未確認事項は推測で埋めず、確認事項として残す。

## 表記

- 個人サイトは自然な「です・ます」調を基本とする。見出しや操作ラベルは簡潔にする。
- 英数字の前後に機械的な空白を挿入しない。固有名詞の表記は尊重する。
- 専門用語は必要な箇所で動作と結び付ける。技術名の列挙だけで説明を終えない。
- 対象が分かるリンク文言を使う。具体名が近くにある場合は冗長な文言を避ける。

## 完了条件

各文について「誰が、何をしたという事実か」「その文がないと失われる情報は何か」「出典はどこか」を説明できること。説明できない文は削除または保留する。
